# 기존 HTML 기준 원본

이 폴더는 Next.js/Supabase 이식 작업에서 비교 기준으로 사용하는 기존 HTML 프로젝트의 원본 보관 영역입니다.

## 원칙

- 이 폴더의 파일은 기준점으로 보존하고 직접 수정하지 않습니다.
- 기능이나 디자인을 변경할 때는 `next-app/`에서 구현합니다.
- 기존 HTML과 이식 결과를 비교할 때 이 폴더의 파일을 기준으로 확인합니다.
- 원본 변경이 꼭 필요하면 먼저 날짜가 포함된 별도 스냅샷을 만든 뒤 변경합니다.

## 포함 파일

- `index.html`: 기존 메인 화면
- `app.js`: 기존 상태·필터·팝업·OCR·브리핑 로직
- `style.css`: 기존 공통 스타일
- `rentals.html`: 임대 매물 화면
- `sales.html`: 매매 매물 화면
- `customers.html`: 고객장부 화면
- `office.html`: 중개사무소 화면
- `브리핑.html`: 브리핑 출력 기준 화면
